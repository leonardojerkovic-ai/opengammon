# OpenGammon

Open backgammon infrastructure: engine, format, API, and a web analysis tool.
**LeoBG** is the name of the engine within this project.

This project does not position itself as "better than XG". It aims to be the open
infrastructure the backgammon community currently lacks. Surpassing XG on cube
decisions is a research goal (Phase 9), not a promise.

Full scope and phase plan: [`OPENGAMMON.md`](./OPENGAMMON.md).
Contributor and session workflow rules: [`CLAUDE.md`](./CLAUDE.md).

## Status

**Phase 0 — Foundations.** Workspace and CI scaffolding only. No engine code yet.
